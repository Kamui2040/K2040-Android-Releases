## New in 0.16.0

- optional companion with rewards and small local interactions;
- locally name the companion and back it up separately;
- local PDF reports created directly on the device;
- language, theme, and usability improvements;
- unified first launch with information, changelog, licence, and credits;
- first open-source release of Esca Agnellis;
- still no Internet permission, accounts, ads, telemetry, analytics, cloud synchronization, or background collection.

## Updating and compatible download channels

The developer APK retains the same package ID and permanent K2040 signing identity. When additional stores are approved, the exact same developer APK should be used wherever the store permits it. This allows users to move between compatible developer-signed download channels.

Independently signed builds, including normal F-Droid builds using a separate signing identity, cannot directly update over this developer APK or be updated by it.

## Privacy

Esca Agnellis has no Internet permission. Tracking and optional companion data remain local. Backups and PDF reports are written only after an explicit user action to an Android document location selected by the user.
