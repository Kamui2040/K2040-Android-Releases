# Esca Agnellis v0.15.0

[Deutsche Version](esca-agnellis-v0.15.0.md)

Esca Agnellis v0.15.0 was the first stable public release after the two public beta versions.

## What changed

- added app-language choices for German, English, Spanish, French, Portuguese (Portugal), and the device language;
- redesigned Settings with clearer language and theme choices;
- added light, dark, and cozy pastel themes;
- improved spacing, scrolling, and touch handling in Settings;
- improved long translated labels and portion descriptions on narrow screens.

## Updating

Compatible public versions can update without removing normal app data and settings. Older private Esca versions and older backup formats are not supported.

Create a current backup before updating or testing an older release.

## Privacy

The app has no Internet permission and uses no accounts, ads, analytics, telemetry, cloud sync, or automatic crash reporting. App data stays on the device.

## Known issues

No confirmed public issues were known for this release. The extra-count badge in mixed rows is intentional behavior.

## Status

This was a stable public release.
