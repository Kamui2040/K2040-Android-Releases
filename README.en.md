## Project pages

- Main K2040 page: <https://kamui2040.github.io/>
- Android Projects: <https://kamui2040.github.io/K2040-Android-Releases/>
- Gaming Mods: <https://kamui2040.github.io/K2040-Gaming-Mods/>

The Android Projects site brings current apps, download links, screenshots, privacy information, and updates together in one place.

## Releases

Each app's public source repository is the authoritative GitHub home for current and future K2040 releases, release files, checksums, and app-specific documentation. Older Esca Agnellis releases that were published from this catalogue repository remain available where they still support existing public download or verification links.

## Current apps

### GeoJoystick

GeoJoystick provides a joystick-style way to control Android mock locations.

- App page: <https://kamui2040.github.io/K2040-Android-Releases/apps/geojoystick/>
- Source, documentation, and GitHub releases: <https://github.com/Kamui2040/K2040-GeoJoystick>
- Current GitHub release: <https://github.com/Kamui2040/K2040-GeoJoystick/releases/tag/v0.1.4>
- F-Droid: <https://f-droid.org/packages/com.k2040.geojoystick/>
- APKPure: <https://apkpure.com/p/com.k2040.geojoystick>
- Uptodown: <https://geojoystick.en.uptodown.com/android>

### Esca Agnellis

Esca Agnellis is a simple, private food-pyramid tracker that keeps its data on the device.

- App page: <https://kamui2040.github.io/K2040-Android-Releases/apps/esca-agnellis/>
- Source and documentation: <https://github.com/Kamui2040/Esca-Agnellis-Android>
- Current GitHub release: <https://github.com/Kamui2040/Esca-Agnellis-Android/releases/tag/v0.16.0>
- F-Droid: <https://f-droid.org/packages/com.k2040.escaagnellis/>
- APKPure: <https://apkpure.com/p/com.k2040.escaagnellis>
- Uptodown: <https://esca-agnellis.en.uptodown.com/android>

## Downloads

Use the official links above. The app's public source repository is the authoritative K2040 GitHub release source. F-Droid builds and signs its own packages from public source, so an F-Droid build may not install directly over a K2040-signed APK.

## Security

Do not post private or security-sensitive information in a public issue. See [SECURITY.en.md](SECURITY.en.md) for the private GitHub security-reporting route.
