Dieses öffentliche Repository enthält die K2040-Android-Projektseite und bewahrt historische Release-Daten auf, die hier veröffentlicht wurden, bevor die öffentlichen App-Repositories zum normalen Veröffentlichungsort wurden.

## Projektseiten

- K2040-Hauptseite: <https://kamui2040.github.io/>
- Android-Projekte: <https://kamui2040.github.io/K2040-Android-Releases/>
- Spiele-Mods: <https://kamui2040.github.io/K2040-Gaming-Mods/>

Die Android-Projektseite bündelt die aktuellen Apps, Downloadlinks, Screenshots, Datenschutzinformationen und Updates.

## Veröffentlichungen

Künftig ist das jeweilige öffentliche Quellrepository die maßgebliche GitHub-Anlaufstelle für neue K2040-Releases, Release-Dateien, Prüfsummen und app-spezifische Dokumentation. Bereits veröffentlichte Esca-Agnellis-Releases und Prüfsummen bleiben hier erhalten, damit bestehende öffentliche Links weiterhin funktionieren; sie werden nicht nachträglich gelöscht oder verschoben.

### Esca Agnellis

Esca Agnellis ist ein einfacher, privater Ernährungspyramiden-Tracker, der seine Daten auf dem Gerät speichert.

- App-Seite: <https://kamui2040.github.io/K2040-Android-Releases/apps/esca-agnellis/>
- Quellcode und Dokumentation: <https://github.com/Kamui2040/Esca-Agnellis-Android>
- Bestehendes GitHub-Release v0.16.0: <https://github.com/Kamui2040/K2040-Android-Releases/releases/tag/esca-agnellis-v0.16.0>
- F-Droid: <https://f-droid.org/packages/com.k2040.escaagnellis/>
- APKPure: <https://apkpure.com/p/com.k2040.escaagnellis>
- Uptodown: <https://esca-agnellis.en.uptodown.com/android>

Die bereits veröffentlichten release-spezifischen Hinweise, historischen Lizenzinformationen, Prüfsummen und das Release v0.16.0 von Esca bleiben in diesem Repository erhalten. Künftige K2040-GitHub-Releases sollen aus dem öffentlichen Esca-Quellrepository veröffentlicht werden und damit demselben Modell wie GeoJoystick folgen.

## Downloads

Nutze die oben verlinkten offiziellen Quellen. Für neue Releases ist das öffentliche Quellrepository der App die maßgebliche K2040-GitHub-Release-Quelle. Historische Esca-Dateien, die aus diesem Repository veröffentlicht wurden, bleiben für bestehende Versionen und Links verfügbar. F-Droid baut und signiert seine Pakete selbst aus dem öffentlichen Quellcode. Deshalb lässt sich eine F-Droid-Version möglicherweise nicht direkt über eine von K2040 veröffentlichte APK installieren.
