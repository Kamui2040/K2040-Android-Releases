## Downloads

Nutze die oben verlinkten offiziellen Quellen. Das öffentliche Quellrepository der App ist die maßgebliche K2040-GitHub-Release-Quelle. F-Droid baut und signiert seine Pakete selbst aus dem öffentlichen Quellcode. Deshalb lässt sich ein F-Droid-Build möglicherweise nicht direkt über eine von K2040 signierte APK installieren.
